# Lumina go-to-market kit

| Folder | What is inside |
|---|---|
| `email/` | `lumina-intro-email.html`, a designed email for warm leads, after-meeting follow-ups and newsletters. Images load from live URLs in `email/images/`. `lumina-intro-email-preview.png` shows how it looks. |
| `social/` | 10 posts at 1080x1350 (LinkedIn, Instagram, Facebook), a 5-slide carousel at 1080x1080, a 1584x396 LinkedIn company banner, and personal banners for Chesney, Siya and Trevor. |
| `print/` | One-page A4 flyer (PDF for printing, PNG for WhatsApp). |
| `sales/` | `Lumina_Lead_Tracker.xlsx`, with a Leads sheet (dropdowns, overdue highlighting), a Dashboard that updates by itself, and a Weekly log. |

## Using the HTML email

1. Open `lumina-intro-email.html` in Chrome, press Ctrl+A, then Ctrl+C.
2. Paste the copy into a new Gmail or Outlook message.
3. Replace everything in [square brackets] and set the button link to your booking page.

For the first cold emails, use the plain-text sequences in the Go-To-Market doc instead. Plain emails land in the inbox more often. Use the designed email once someone has replied, after a meeting, or for newsletters.

## Social posts

Each post matches a caption in the content calendar inside the Go-To-Market doc. Post files are numbered in the order they appear in the calendar.
